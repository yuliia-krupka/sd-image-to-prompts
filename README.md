# 🎨 Stable Diffusion — Image to Prompts

> Given an image generated by Stable Diffusion, predict the text prompt that produced it.

[Kaggle Competition](https://www.kaggle.com/competitions/stable-diffusion-image-to-prompts)

---

## How it works

1. **BLIP-Large** generates a caption from the input image
2. **MiniLM** encodes the caption into a 384-dim embedding
3. Submissions are scored by cosine similarity between predicted and ground-truth embeddings

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Set up Kaggle API token

```bash
mkdir -p ~/.kaggle
echo '{"username":"YOUR_USERNAME","key":"YOUR_KEY"}' > ~/.kaggle/kaggle.json
chmod 600 ~/.kaggle/kaggle.json
```

### 3. Download models

```bash
python app/download_model.py
```

### 4. Run the app

```bash
streamlit run app/app.py --server.fileWatcherType none
```
